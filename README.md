
# Maryland - Піньяти для свят

**Maryland** — це яскравий та інтерактивний веб-сайт (Landing Page) для майстерні з виготовлення піньят. Сайт дозволяє клієнтам переглядати великий каталог продукції, дізнаватися деталі про кожну піньяту та зручно оформлювати замовлення онлайн.

## Основний функціонал

* **Динамічний каталог:** Велика галерея піньят із можливістю горизонтального скролінгу та кнопкою для розгортання всього списку.
* **Пошук та фільтрація:** "Живий" пошук по назві піньяти, який миттєво фільтрує товари на сторінці без перезавантаження.
* **Модальні вікна:** Кожна піньята має власне спливаюче вікно з детальним описом, розмірами та кнопкою замовлення.
* **Валідація форми:** Клієнтська перевірка введених даних (формат телефону `+380...`, правильність email, перевірка обраної піньяти зі списку `datalist`).
* **Відправка замовлень на Email:** Інтегрований бекенд на PHP (з використанням PHPMailer), який асинхронно (через AJAX) відправляє деталі замовлення на пошту адміністратора сайту.
* **Адаптивний дизайн:** Коректне відображення сайту на мобільних телефонах, планшетах та комп'ютерах (реалізовано через CSS Media Queries та бокове виїзне меню).

## 🛠 Технологічний стек

* **Frontend:**
  * HTML5 (семантична розмітка).
  * CSS3 (Flexbox, анімації, плавний скролінг, стилізація скроллбару).
  * Vanilla JavaScript (DOM-маніпуляції, AJAX-запити через `fetch`, слайдер, обробка модальних вікон).
* **Backend:**
  * PHP 7.4+.
  * Бібліотека [PHPMailer](https://github.com/PHPMailer/PHPMailer) для безпечної відправки листів через SMTP (Gmail).

## Структура проекту

* `index.html` — Головна сторінка сайту з розміткою каталогу, форми та відгуків.
* `siet.css` — Файл стилів для всього сайту.
* `siet.js` — Клієнтська логіка: валідація, пошук, слайдер банерів, робота з формою.
* `sendmail.php` — PHP-скрипт для збору даних з POST-запиту та відправки листа.
* `config.php` — Конфігураційний файл для зберігання доступу до пошти (SMTP).
* `img/` — Папка із зображеннями піньят, логотипом та банерами (очікується в корені).
* `phpmailer/` — Папка з бібліотекою PHPMailer (необхідна для роботи бекенду).

## Встановлення та локальний запуск

Оскільки проект використовує PHP для відправки листів, для його повноцінної роботи потрібен локальний сервер (наприклад, XAMPP, MAMP, OpenServer).

1. **Клонуйте репозиторій** у папку вашого локального сервера (наприклад, `htdocs` для XAMPP):
   ```bash
   git clone [https://github.com/ВашЛогін/НазваРепозиторію.git](https://github.com/ВашЛогін/НазваРепозиторію.git)
   cd НазваРепозиторію



2. **Завантажте PHPMailer:**
Переконайтеся, що у корені вашого проекту є папка `phpmailer/src/`, яка містить файли `Exception.php`, `PHPMailer.php` та `SMTP.php`.
3. **Налаштуйте пошту (SMTP):**
* Створіть файл `config.php` у корені проекту (якщо він не додався з git).
* Впишіть туди свої дані від пошти (рекомендується використовувати "Паролі додатків" від Google, а не основний пароль від акаунту):


```php
<?php
return [
    'email' => 'ваш_email@gmail.com',
    'password' => 'ваш_пароль_додатку'
];
?>

```



## Як працює форма замовлення

1. Клієнт заповнює форму у модальному вікні.
2. Скрипт `siet.js` перевіряє правильність введених даних (номери телефонів, наявність піньяти у списку).
3. Якщо все добре, дані асинхронно передаються у файл `sendmail.php`.
4. PHPMailer формує HTML-лист і відправляє його на вказану пошту адміністратора (`astylell00@gmail.com`).
5. Користувач бачить вікно про успішне замовлення, а форма автоматично очищується.
